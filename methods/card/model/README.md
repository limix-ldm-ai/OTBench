# CARD source is not redistributed

The reviewed upstream source did not provide a license granting permission to
redistribute its code. OTBench therefore excludes the upstream implementation
and the adapter routines derived from it. This directory contains no model code.

Obtain the source directly from the authors' project homepage:

- [CARD](https://github.com/XzwHan/CARD)

Review the upstream terms and obtain any necessary permission before using,
modifying, or redistributing that source. The OTBench project license does not
grant rights to the excluded upstream code. This notice does not determine
whether a later upstream revision supplies a license.

The `card` registry entry is retained for identification, but it is an
**unavailable external-only placeholder** in this distribution. Training and
prediction raise an actionable error. Copying files into this directory alone
does not enable an adapter; OTBench does not include an external-code loader.
