# Gaussian-copula baseline

The implementation in this directory expresses the standard Gaussian-copula
construction and multivariate-normal conditioning using NumPy, pandas, and
SciPy. It does not bundle or import the `sdv-dev/Copulas` implementation.
The Copulas project URL in earlier method metadata was an algorithm reference,
not the source of a vendored backend.

These baseline implementation files use the root OTBench `LICENSE.txt`.
Installed scientific Python dependencies retain their own licenses.
