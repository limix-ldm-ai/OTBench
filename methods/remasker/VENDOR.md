# ReMasker redistribution exclusion

No upstream ReMasker code is bundled in OTBench. The reviewed source supplied
no redistribution license, so its model files, copied or translated adapter
routines, and upstream-derived configuration were removed from this release.

See [the exclusion notice](model/README.md) and obtain the source directly from
[the authors' project](https://github.com/tydusky/remasker), subject to its applicable terms.

The remaining adapter is an OTBench-authored unavailable placeholder, not a
ReMasker implementation. No automatic download or execution is provided.
